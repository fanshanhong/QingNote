## 优先修复建议

按影响范围和实现难度排序的 Top 10 差距项：

### 1. [高优] 宫格视图（笔记列表宫格展示.jpg）
- **影响**：核心 UI 功能缺失，用户无法切换列表/宫格视图
- **工作量**：中等（需添加 StaggeredGridLayoutManager + 卡片 layout 适配 + overflow 菜单项）
- **涉及文件**：NoteListActivity.kt、NoteListAdapter.kt、item_note_card.xml、menu_note_list_overflow.xml

### 2. [高优] 批量选择删除模式（批量删除.jpg）
- **影响**：核心交互功能缺失，用户无法批量管理笔记
- **工作量**：中等（需添加选择模式状态管理 + checkbox UI + 底部操作栏 + overflow 菜单项）
- **涉及文件**：NoteListActivity.kt、NoteListAdapter.kt、item_note_card.xml

### 3. [高优] overflow 菜单补全（笔记列表右上角功能菜单.jpg）
- **影响**：缺少"宫格视图"、"批量删除"、"设置"3个菜单项
- **工作量**：低（菜单 XML + 对应点击事件）
- **涉及文件**：menu_note_list_overflow.xml、NoteListActivity.kt

### 4. [中优] 分享功能实现（选择分享方式弹窗.jpg）
- **影响**：分享按钮目前仅弹 Toast，功能完全缺失
- **工作量**：中等（需实现分享为图片/文本/文档三种方式 + BottomSheet UI）
- **涉及文件**：NoteEditorActivity.kt、新增 share 相关布局和逻辑

### 5. [中优] 卡片星标图标显示逻辑优化（列表页默认状态.jpg）
- **影响**：参考图中无星标笔记不显示星标图标，当前始终显示空心星标
- **工作量**：低（visibility 控制）
- **涉及文件**：NoteListAdapter.kt

### 6. [中优] 卡片布局调整 — 时间显示位置（列表页默认状态.jpg）
- **影响**：参考图中时间在标题下方单独一行（列表视图），当前时间在标题右侧同行
- **工作量**：低（调整 item_note_card.xml 布局）
- **涉及文件**：item_note_card.xml、NoteListAdapter.kt

### 7. [中优] 卡片边框去除（列表页默认状态.jpg）
- **影响**：参考图卡片无可见边框线，当前有 0.5dp #E8E8E8 描边
- **工作量**：极低（移除 strokeWidth/strokeColor 属性）
- **涉及文件**：item_note_card.xml

### 8. [低优] 语音标识小图标（列表页默认状态.jpg）
- **影响**：含语音的笔记在列表中无麦克风图标标识
- **工作量**：低（在卡片时间前添加条件性 ImageView）
- **涉及文件**：item_note_card.xml、NoteListAdapter.kt

### 9. [低优] 样式面板精简（笔记-编辑状态-弹出样式弹窗.jpg）
- **影响**：当前比参考图多出 S（删除线）按钮和 H1-H6 行，与华为原版不一致
- **工作量**：低（移除或隐藏多余按钮行）
- **涉及文件**：dialog_style_picker.xml

### 10. [低优] "管理"按钮中间弹窗（文件夹管理的弹窗.jpg）
- **影响**：参考图点击"管理"先弹 PopupMenu（新建文件夹/编辑），当前直接跳转管理页
- **工作量**：低（添加 PopupMenu 中间层）
- **涉及文件**：NoteListActivity.kt（rebuildFilterPanel 中的 onManageFolders 回调）
